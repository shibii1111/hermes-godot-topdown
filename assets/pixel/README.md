# Art Assets

This folder contains original RogueWatch visual assets.

Current status:

- M6.0 started the real asset pipeline instead of deferring all art to the final polish pass.
- M6.0.1 pivots the approved direction from strict pixel art to **A1.5 Clean Readable Clockpunk**.
- Existing early PNGs may remain as temporary placeholders, but future production assets should follow `docs/art_direction.md`.
- Planned categories: player, enemies, dungeon fixtures, hub fixtures, props, UI icons, slash/hit effects, dash trail, portals, and pickups.

Project rule:

- Do not import commercial, unlicensed, or third-party assets.
- Repository assets should be original and committed as `.png` files when produced.
- Keep collisions and gameplay hitboxes independent from sprite artwork.
- Sprite source canvases should use even-numbered dimensions, but they do not need to be square.

See `docs/art_direction.md` for the current art direction, scale, palette, and integration rules.
