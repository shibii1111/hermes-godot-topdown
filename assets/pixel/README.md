# Pixel Art Assets

This folder is reserved for original RogueWatch pixel art assets.

Current status:

- Early gameplay milestones still use procedural Godot geometry for speed and validation.
- Real original 32x32 `.png` pixel art will replace placeholder geometry during the art/polish pass.
- Planned categories: player, enemies, dungeon tiles, hub tiles, props, UI icons, slash/hit effects, dash trail, and pickups.

Project rule:

- Do not import commercial, unlicensed, or third-party assets.
- Repository assets should be original and committed as `.png` files when produced.
