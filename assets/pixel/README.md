# Pixel Art Assets

This folder contains original RogueWatch pixel art assets.

Current status:

- M6.0 starts the real asset pipeline instead of deferring all art to the final polish pass.
- Early sprites are intentionally simple, but they use the final folder structure and Godot integration pattern.
- Planned categories: player, enemies, dungeon tiles, hub tiles, props, UI icons, slash/hit effects, dash trail, and pickups.

Project rule:

- Do not import commercial, unlicensed, or third-party assets.
- Repository assets should be original and committed as `.png` files when produced.
- Keep collisions and gameplay hitboxes independent from sprite artwork.

See `docs/art_direction.md` for the current art direction, scale, palette, and integration rules.
